# Teste de Software — DCT2304

Página da disciplina **Teste de Software (DCT2304)** do BSI-UFRN.

## Processo YP-Agentic

O processo **YP-Agentic** (8 fases, iterações de 2 semanas, desenvolvimento assistido
por agentes de IA) é o mesmo adotado em Engenharia de Software. Os artefatos de teste
são produzidos dentro desse processo — não são um fluxo paralelo.

- [Visão geral e estrutura do YP-Agentic](../yp-agentic/README.md)
- [Manual passo a passo](../yp-agentic/manual-passo-a-passo.md)
- [Fluxo do processo (8 fases)](../yp-agentic/processo/fluxo.md)
- [Catálogo de prompts](../yp-agentic/prompts/README.md)
- [Catálogo de templates](../yp-agentic/templates/README.md)

**Onde os artefatos de teste aparecem no fluxo:**

| Artefato de teste | Fase | Template |
|---|---|---|
| Plano Geral de Testes | F3 — Planejamento de Releases | [`plano-geral-testes.md`](../yp-agentic/templates/plano-geral-testes.md) |
| Plano de Teste da Iteração | F4 — Planejamento da Iteração | [`plano-teste-iteracao.md`](../yp-agentic/templates/plano-teste-iteracao.md) |
| Relatório de Testes | F6 — Implantação | [`relatorio-testes.md`](../yp-agentic/templates/relatorio-testes.md) |

Use os prompts correspondentes em [`prompts/`](../yp-agentic/prompts/README.md) para
gerar cada um deles a partir do template oficial.
